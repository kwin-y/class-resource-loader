Project Description

This project is a small page(Class Resource Loader) that loads three class resources after a simulated delay. The shows loading, success, and failure, count accepted requests, and remain responsive while it waits. It uses JavaScript events, closures, promises, async and await, and classes together.


Resources

The successful request displays:

- JavaScript Events | 15 min
- Closures Practice | 20 min
- Promises and Await | 25 min

Features

- Counts accepted resource-loading attempts using a closure.
- Counts response-button clicks using a separate closure.
- Prevents overlapping resource requests with a busy flag.
- Captures the failure mode when a request is accepted.
- Displays loading, success, and failure states.
- Uses `Resource` and `TimedResource` classes.
- Uses inheritance and method overriding.
- Displays an execution trace showing synchronous code, a Promise microtask, a timer task, success/failure, and cleanup.
- Keeps the response button usable while resources are loading.
